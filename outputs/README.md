# Outputs Directory

This directory contains the results generated from the data analysis.

## Generated Outputs

Typical outputs from the analysis include:

### Beach Risk Ranking

A dataset containing aggregated metrics for each monitored beach, including:

- Average E. coli concentration
- Maximum observed contamination
- Frequency of unsafe water events
- Total number of samples
- Composite risk score
- Priority classification

### Monitoring Priority Classification

Beaches are classified into three monitoring priority categories:

- High Priority
- Medium Priority
- Low Priority

This classification helps identify locations that may require increased monitoring frequency or additional investigation.

### Spatial Visualization

Risk scores and priority levels can be visualized using GIS tools such as QGIS to produce maps highlighting higher-risk recreational water sites.

## Purpose

These outputs provide decision-support information for prioritizing monitoring efforts and identifying potential environmental risk drivers.
